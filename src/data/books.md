# Library

Source of truth for the Index section. Books are grouped under year
headings; the special heading `## Currently Reading` pins entries to the
top of the library list.

## Format

One markdown table per year (or under `## Currently Reading`):

| Title | Author | Finished | Note |
|-------|--------|----------|------|

- **Title** — required, rendered italic.
- **Author** — required, displayed `Surname, Given` if a comma is present.
  If you leave it blank when editing, ask Claude to fill it in — Claude will
  edit this file directly using its own knowledge of the book.
- **Finished** — optional short tag (e.g. `Mar`, `Mar 2026`). Leave blank to omit.
- **Note** — optional marginalia, kept short. Leave blank to omit.

**Bilingual titles & authors** — for Chinese (or other CJK) input, use the
syntax `中文 / English` in the Title or Author cell. The CJK side renders
prominent; the English appears in a smaller italic right after, separated
by a coral middle-dot (titles) or hair-space (authors). English-only cells
are untouched — internal slashes in English titles are safe.

Entries below are placeholders — replace with your own.
