# Library

Source of truth for the Index section. Books are grouped under year
headings; the special heading `## Currently Reading` pins entries to the
top of the library list.

## Format

One markdown table per year (or under `## Currently Reading`):

| Title | Author | Finished | Note |
|-------|--------|----------|------|

- **Title** — required, rendered italic.
- **Author** — required, displayed `Surname, Given` if a comma is present.
- **Finished** — short tag (e.g. `Mar`, `Mar 2026`). Free text.
- **Note** — optional marginalia, kept short.

Entries below are placeholders — replace with your own.
